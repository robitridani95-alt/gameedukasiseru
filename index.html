Tebak Kategori AR

Beberapa kotak kategori akan muncul di atas (misalnya BUAH, HEWAN, WARNA). Angkat tanganmu di depan kamera, arahkan ujung jari telunjukmu ke benda emoji di bawah, lalu seret setiap benda ke kotak kategorinya yang tepat — misalnya 🍎 diseret ke kotak BUAH. Tidak ada kamera? Pakai mouse atau sentuh layar saja.

⚠️ File ini dibuka langsung dari komputer (file://). Browser memblokir akses kamera di mode ini. Buka lewat server lokal (mis. jalankan python -m http.server lalu akses http://localhost:8000) atau upload ke hosting/Google Drive-Vercel, baru kamera bisa jalan. Mode mouse/sentuh tetap bisa dipakai tanpa syarat ini.
